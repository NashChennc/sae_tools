# Dataset Adapters

Dataset adapters provide a unified interface for loading and adapting safety and
jailbreak datasets into a standardized format.

## Usage

```python
from sae_tools.adapters.datasets import get_adapter

adapter = get_adapter("WildGuardTest")
dataset = adapter.load("path/to/dataset", max_samples=100)

print(dataset[0])
```

## Unified Output Format

All dataset adapters return records with the following structure:

```python
{
    "prompt": str,
    "response": str,
    "prompt_label": str | None,
    "response_label": str | None,
    "category": str,
    "source": str,
}
```

`prompt_label` and `response_label` use `"Safe"`, `"Unsafe"`, or `None`.

## Category Format

The `category` field is a JSON string generated by `make_category`.

* `harm:` keys are safety categories, for example `{"harm:Violence": 1.0}`.
* `meta:` keys are metadata or flags, for example `{"meta:adversarial": 1.0}`.
* Values are floats normalized to `[0.0, 1.0]`.

Category parsing and label construction for analysis lives in
`sae_tools.analysis.category`.

## Adding a New Adapter

1. Create a class inheriting from `BaseAdapter`.
2. Implement `transform(self, example)` to map raw fields to the unified format.
3. Register the class in `sae_tools/adapters/datasets/registry.py`.
