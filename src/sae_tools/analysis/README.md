# analysis/

`sae_tools.analysis` is the canonical namespace for analysis code that consumes
normalized datasets and saved SAE activation outputs.

## Submodules

* `category`: parse adapter category fields and build binary labels.
* `statistical`: feature metrics, aggregation, and PR-space visualization.
* `geometric`: decoder-vector norm, similarity, and UMAP workflows.
* `dashboard`: notebook-oriented feature activation views.

Dataset loading, model loading, and SAE checkpoint loading are kept under
`sae_tools.adapters` and `sae_tools.model`; analysis modules should consume their
outputs rather than owning resource-specific loading conventions.

## Activation Artifacts

Statistical and dashboard analysis require activation `.pt` files generated by
`0_generate_activations.py` before any analysis runs. Use
`sae_tools.analysis.artifacts.find_latest_activation_file` in notebooks and scripts
to locate the newest matching run and fail with an explicit generation command when
the file is missing.
